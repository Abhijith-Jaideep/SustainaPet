# Carbon Pawprint 🌱
A Flask-based backend system for managing carbon points, quests, and rewards.

## Table of Contents
- [Features](#features)
- [Installation](#installation)
- [Usage](#usage)
- [API Endpoints](#api-endpoints)

## Features
- Weekly quest allocation (3 quests per user)
- Quest completion updates carbon points and pet mood
- Reroll quests functionality
- Dashboard shows user statistics
